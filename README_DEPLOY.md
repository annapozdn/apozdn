# Публикация сайта `apozdn`

Единый источник правды — репозиторий `annapozdn/apozdn`, ветка `main`.

Vercel-проект `apozdn` подключён к GitHub и публикует ветку `main` на домен:

- `https://apozdn.vercel.app`

## Главное правило

Не работать в `safety-note` и не создавать отдельные локальные HTML-версии как рабочие.

Все правки, которые должны попасть на сайт, нужно коммитить в `main`.

## Балкон

Единственная актуальная страница балкона:

- URL: `/dom/balcony`
- файл: `dom/balcony.html`
- фото: `photos/`

Файл `balcony.html` в корне не является рабочей страницей. Он оставлен только как служебная заглушка со ссылкой на `/dom/balcony`, чтобы не было второй версии.

## Как работать Claude Code

1. Открыть репозиторий `annapozdn/apozdn`.
2. Убедиться, что активна ветка `main`.
3. Править только нужный файл, например `dom/balcony.html`.
4. Не менять `/family-tree`, если задача не про древо.
5. Сделать коммит в `main` и push.
6. Vercel сам запустит деплой.

## Как работать ChatGPT/GitHub-коннектору

1. Читать и менять файлы в ветке `main`.
2. Для балкона использовать только `dom/balcony.html`.
3. Не использовать ветку `safety-note` как рабочую.
4. Не создавать `dom/balcony/index.html` и другие дубли страницы.

## Проверка после публикации

После деплоя открыть:

- `https://apozdn.vercel.app/dom/balcony`

На актуальной странице должны быть:

- длина 690 см;
- ширина 105 см;
- потолок 270 см;
- подоконник около 115 см;
- блок «Новые замеры»;
- подписи в галерее отдельным белым блоком под фото, а не поверх изображения.
