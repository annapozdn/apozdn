# Не использовать как production-источник старого сайта

Этот репозиторий подключён к Vercel-проекту `apozdn`, но старый сайт с `/family-tree` был создан не из этого репозитория.

Пока исходники старого сайта не найдены, нельзя пушить сюда полноценный сайт в `main`: это может заменить текущий production-деплой и снова сломать `/family-tree`.

Для балкона лучше создать отдельный проект/репозиторий или сначала перенести исходники старого сайта.
